# Créditos — OpenCulin (Tron Legacy JS)

## Código y diseño

- Demo JavaScript + Canvas 2D desarrollada para el proyecto educativo / marketing de ArcasShred Pro.
- Estética de referencia (UI, tono): Detroit: Become Human (inspiración de estilo, no assets).

## Gráficos

- Gráficos **procedurales** (círculos, rectángulos, gradientes, grid) generados en tiempo de ejecución.
- No se utilizan sprites ni modelos de terceros en esta versión.

## Tipografía

- Fuentes del sistema (`Segoe UI`, system-ui). Si se añaden Google Fonts u otras, documentar aquí la licencia.

## Audio

- Esta build no incluye pistas de audio externas (silencio documentado). Si se añaden:
  - Indicar fuente (p. ej. Freesound, Kevin MacLeod, etc.).
  - Indicar licencia exacta (CC0, CC-BY, royalty-free…).
  - Cumplir atribución exigida por la licencia.

## Datos y textos

- Diálogos y mensajes educativos: contenido original del proyecto.
- Conceptos técnicos (FTL, sobrescritura, borrado criptográfico): divulgación; las afirmaciones marcadas deben validarse con especialista antes de uso comercial.

## Aviso legal

- El nombre de trabajo “Tron Legacy” no implica afiliación con la franquicia audiovisual homónima.
- Título mostrado: configurable en `data/config.json`.
- No se usan assets, música ni diseños protegidos de terceros sin licencia compatible con uso promocional.

## Cómo actualizar este archivo

Al incorporar cualquier asset externo:

1. Nombre del archivo / recurso.
2. Autor o fuente.
3. Licencia y enlace.
4. Uso en el proyecto (música de fondo, SFX, tipografía, etc.).

## Audio

- Banda sonora **procedural** generada en el navegador con Web Audio API (pads, bajo, arpegios).
- Estética electrónica / tecno-noir de género.
- **No** se utilizan pistas, samples ni composiciones de la franquicia audiovisual Tron ni de terceros con derechos de autor.
